## 백업·장애 복구 인수

| 항목 | 합격 기준 | 실제 결과/증거 |
|---|---|---|
| 수동 백업 | 로컬 백업과 NAS 완료 폴더 생성, manifest/DB 파일 존재 | 미실행 |
| 보관 점검 | check_backups로 최신성·체크섬 통과, 중단 폴더 없음 | 미실행 |
| NAS 단절 시험 | NAS 실패 표시, 로컬 백업 보존, 재연결 후 복사 가능 | 미실행 |
| 예약 백업 | 회사 실행 계정의 예약 작업 성공·다음날 새 백업 생성 | 미실행 |
| 새 DB 복원 | 별도 빈 DB에 복원, 재고/예약/최근 거래/사용자 확인 | 미실행 |
| 복구 후 업무 | 시험 로그인·조회·거래·운영 점검 통과 | 미실행 |
| 계정 인계 | 회사가 DB/서비스/NAS/인증서 복구 수단 보유, DPAPI 계정 변경 시 재준비 | 미실행 |

체크섬 검증은 파일 손상 검출이다. 암호화/출처 인증이나 실제 복원 가능성 검증을 대신하지 않는다. 실행 중 복사 임시 폴더가 보이면 작업이 끝난 뒤 다시 점검한다. 실제로 중단됐다면 로그와 정상 로컬 원본을 확인한 뒤 처리하며 자동 삭제하지 않는다.
