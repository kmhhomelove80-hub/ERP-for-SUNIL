# 검증 결과와 운영 전 남은 조건

## 현재 확보한 검증

- SQLite: 테스트 64개 발견, 61개 통과, PostgreSQL 전용 3개 skip.
- PostgreSQL 17.11: 테스트 64개 발견, 62개 통과, SQLite 파일 백업 전용 2개 skip. 예약 경합/반대 방향 이동/중복 요청의 동시성 테스트 포함.
- PostgreSQL 별도 백업/복원 실행 검증: 새 DB 복원 후 모든 테이블 건수, 재고/예약/감사 내용 일치. 기존 데이터가 있는 DB에 재복원 차단.
- 실제 첨부 파일을 격리 DB에 이관: 현재고 25,754, 예약 5,460. 재고 620행/품번 451/활성 예약 161행 일치.
- 과거 이력 전 행 payload 비교: 입고 2,999 / 피킹·출고 8,215 / 로그 14,792 / AppSheet 이동 149. AS 제외.
- ERP 원본 1,342행(Y09 450, Y02 892), 원본 음수 10행 보존. ERP 누락까지 합친 비교 1,347행. Y09 차이/누락 12항목을 원본 수량으로 대조했다. 실사 결과가 아니라 첨부 파일 기준 비교다.
- 실제 파일 이관 DB의 SQLite 백업 복원 후 모든 테이블 건수 일치. 원본 두 파일 해시 전후 일치.
- 실제 Chromium/Playwright: 모바일 390×844 요청→PC 처리→완료 조회, 이력 검색, 피킹/PDF, ERP 업로드/대조/원인 기록, Y02 참고값, 입고 등록/취소 통과. JavaScript 오류 없음. 가상 데이터만 사용했다.
- PDF 한글/품번/수량 추출 확인, A4 가로 1페이지 확인.
- Gunicorn 임시 기동과 인증 리다이렉트/로그인 응답 확인.
- collectstatic, 마이그레이션 누락 확인, Django 기본 check 통과.
- Caddy 설정 validate 및 한국 시간 새벽 2시 백업 timer 표현식 확인. Caddy를 공개 서비스로 실행하지 않았다.
- DEBUG=0 배포 check는 HSTS 하위 도메인/브라우저 preload에 관한 W005/W021 2개 경고가 남는다. 도메인 범위가 미확정이므로 둘 다 False이며 경고를 숨기지 않았다. 실제 호스트 정책을 확인한 뒤 결정한다.
- CI 설정 파일을 만들었으나 GitHub Actions 실행/원격 push는 하지 않았다.

## 운영 전 외부 조건

1. 회사 소유 서버/계정과 호스트명, 실제 비용 확인 및 구매 승인. 예산은 연 10만원 내외지만 공급자 요금은 아직 확인하지 않았다.
2. 회사 저장공간의 백업 복사/권한 및 담당자. OneDrive/SharePoint 계정은 아직 연결하지 않았다.
3. 후임자 확정과 실제 PC/휴대폰/외부망 인수 검증.
4. 초기 예정 위치 중 ‘9/10 입고’의 현재 도착 상태 등 데이터 정리. 검증에서는 예정으로 명시했으나 운영 확정값이 아니다.
5. 실제 호스트에서 HTTPS·DB 연결·방화벽·정적 파일·자동 백업·복구를 확인한 뒤 전환한다.

2026-10-31 한국 시간: 공식 서버 가격 페이지 접근은 환경 네트워크 정책으로 403이었다. 가격 조회용 www.hetzner.com / www.vultr.com / aws.amazon.com만 네트워크 초안에 추가 저장했다. 저장은 현재 런타임 적용/게시/서버 구매가 아니다. 도구는 적용에 환경 설정 검토·저장·게시가 필요하다고 반환했다. 사용자의 게시 금지 지시에 따라 직접 게시하지 않았다. 가격 조회는 네트워크가 적용된 후 재시도해야 한다.
