# 입고LIST 웹 실행파일

[inbound-list.html 다운로드](https://github.com/kmhhomelove80-hub/ERP-for-SUNIL/raw/refs/heads/main/tools/inbound-list/inbound-list.html)

파일을 내려받아 Chrome 또는 Edge에서 열어 실행하세요. 서버·설치·인터넷 연결이 필요 없습니다.

1. ERP 재고이동 XLS/XLSX/CSV/TSV 파일을 선택합니다.
2. 분할 수량(예: 20+8)과 최종 비고를 입력합니다.
3. 미리보기를 확인하고 엑셀 다운로드 또는 인쇄/PDF를 선택합니다.

합계 행은 자동 제외하고 원본 상세 행을 유지합니다. 분할 합계가 원본 수량과 다르면 출력을 차단합니다. ERP 적요·비고는 참고용으로 표시하며 최종 비고는 직접 입력합니다. 문서 날짜는 기본 실행일이며 수정할 수 있습니다. XLSX의 첫 시트를 읽고 파일 크기는 20MB 이하를 지원합니다.

업로드 자료는 브라우저 메모리에서 처리하며 서버로 전송하지 않습니다. 새로고침 전 엑셀로 저장하세요. 포함된 예제는 가상 데이터입니다.

검증: 실제 CP949 ERP 파일에서 상세 21행, 18품목, 277개 확인; 분할 검증 및 XLSX 재읽기 통과. 브라우저 화면·실제 인쇄는 미검증입니다.

SheetJS Community Edition 0.18.5 (Apache-2.0)를 포함합니다.

## v1.1
- RAW/ERP 비고의 `32+32`를 자동으로 32, 32 두 행으로 출력합니다. 합계 64를 개별 수량으로 출력하지 않습니다.
- XLSM 통합문서는 RAW 시트를 우선 읽습니다. RAW H열의 분할 비고도 지원합니다.
- 총수량 숨김 체크를 미리보기, 인쇄, 다운로드 엑셀 E열에 반영합니다.
- 규격(D열값)을 표시하고, 미리보기에서 분할된 각 행의 비고를 편집합니다.

## v1.2
- ERP용 복사: 품목코드 / 품목명 / D열값 / 수량 / 비고 순서로 제목·헤더·총수량·선택 체크박스 없이 복사합니다.
- Excel 호환 HTML 표와 탭/CRLF 텍스트를 함께 전달합니다. 브라우저에서 자동 복사를 지원하지 않으면 엑셀 다운로드 후 복사하세요. 대상 ERP에서의 실제 호환성 확인은 필요합니다.
- ERP용 복사는 삭제 후 남은 전체 행을 복사합니다. 체크박스는 삭제할 행 선택용입니다.
- 원본 편집 및 최종 미리보기 앞의 체크박스로 선택 삭제합니다. 미리보기에서는 분할된 개별 행도 삭제할 수 있습니다. 삭제 취소로 직전 삭제를 복구합니다.
- 삭제 후 총수량은 남은 행 기준으로 다시 계산합니다. 분할 수량을 다시 편집하면 해당 원본의 개별 삭제 상태와 행별 비고가 초기화됩니다.
- 총수량 기본 숨김. 출력은 설정과 관계없이 첨부 양식의 5열로 고정합니다.
- 인쇄: A4 가로, 출력 날짜 + 입고 LIST 제목, 남색 표 헤더, 품목코드/품목명/D열값/수량/비고. 브라우저 인쇄창의 머리글·바닥글은 해제하세요. 문서 날짜를 바꾸면 제목에도 반영됩니다.
- DOM 기반 검증: 자동 분할, 클립보드 5열/행 구분, 개별·원본 삭제, 복구, 수량 재계산, XLSX 총수량 숨김 및 행별 비고 통과. 실제 브라우저 인쇄 및 대상 ERP 붙여넣기는 미검증입니다.
