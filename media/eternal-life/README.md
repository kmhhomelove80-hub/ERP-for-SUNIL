# 영생의 선물 · 한국어 음성과 자막

약 3분 40초의 단일 한국어 합성 음성입니다. 사용자 요청으로 대본의 김명환 이름을 유지하여 공개 게시했습니다.

- [MP3 다운로드](https://github.com/kmhhomelove80-hub/ERP-for-SUNIL/raw/refs/heads/main/media/eternal-life/eternal-life-ko.mp3)
- [자막 영상 MP4 다운로드](https://github.com/kmhhomelove80-hub/ERP-for-SUNIL/raw/refs/heads/main/media/eternal-life/eternal-life-ko-subtitled.mp4)
- [전체 ZIP 다운로드](https://github.com/kmhhomelove80-hub/ERP-for-SUNIL/raw/refs/heads/main/media/eternal-life/eternal-life-ko-bundle.zip)

MP3에는 가사(USLT)와 시간 자막(SYLT)을 포함했습니다. 모든 플레이어가 표시하지는 않으므로 자막을 바로 보려면 MP4를 재생하세요. 별도 LRC와 SRT도 제공합니다.

기도의 슬래시는 쉬는 구간으로 처리했고 숫자 목록은 첫째·둘째·셋째로 읽었습니다. 아들아/딸아는 두 표현을 함께 읽습니다. 문장 사이에 쉬는 시간을 넣었습니다. 긴 문장 안의 자막 분할은 음성 구간 길이에 비례해 배분했습니다.

음성은 KSS 기반 Mimic3 한국어 공개 모델을 sherpa-onnx에서 로컬 실행해 합성했습니다. 전문 성우 녹음이 아니며 전체 발음·자연스러움의 사람 청취 검수는 완료하지 않았습니다. MP3 길이, 음성 구간, 자막 시간 순서 및 MP4 자막 배치를 확인했습니다.
