자료 업데이트

최초에는 기준 엑셀을 등록하고, 이후에는 대상별 전체 RAW 데이터만 교체하세요.

최초 기준 자료 등록

ERP·REF·SET과 조선소 원본이 있는 기존 엑셀 ZIP을 읽어 초기 자료를 구성합니다.

이미 자료가 있습니다. 이 작업은 전체 원본과 REF를 초기 등록 파일로 교체합니다. 일반 업데이트는 오른쪽 기능을 이용하세요.

대상별 RAW 전체 교체

빨간색 구분선 오른쪽의 전체 RAW 열을 머리글과 함께 업로드하세요. 선택한 대상만 교체하며 다른 야드 자료는 유지됩니다.

등록 현황

처리 기준 및 추가 예정ERP와 REF 변경 시 전체 야드의 조회 정보를 다시 계산합니다. 중소 자료는 ERP에서 자동 생성합니다. SHI·ICOPS는 규칙 확정 후 같은 구조로 추가합니다. 저장 자료는 프로그램 종료 후에도 유지됩니다.

최근 변경 이력

통합 수주현황

HMD·HHI·HSHI·중소 자료를 한 목록에서 조회합니다. 원본 행을 유지하며, 추출 전에는 행을 합치거나 빈 납품처를 제외하지 않습니다.

상세 필터
자료를 등록해 주세요.100행씩 표시 · 다운로드는 조회 결과 전체
업데이트 탭에서 최초 기준 자료를 등록하세요.

납품리스트 추출

저장된 최신 수주 자료에서 조건에 맞는 목록을 추출합니다.

비워 두면 해당 대상 전체를 추출합니다. HSHI는 ‘POR, 블록’ 형식도 사용할 수 있습니다. POR는 정확히 일치하는 값으로 검색합니다.

기존 추출 기준 유지

HMD는 납품처가 빈 행을 제외합니다.
POR·호선·블록·품명·코드가 같으면 수량만 합산합니다.
나머지 정보와 금액은 첫 번째 행을 유지합니다.
품목코드별 합계는 화면과 엑셀에서 세로로 병합합니다.

추출 결과

대상과 조건을 선택하고 목록 추출을 실행하세요.

REF 관리

기존 REF와 SET을 한곳에서 관리합니다. 저장하면 관련 수주현황과 추출 자료를 다시 계산합니다.

새 거래처 등록

SET은 같은 POR가 여러 개면 기존처럼 첫 번째 등록 행을 조회합니다.

자료는 이 PC의 data/workspace.sqlite3에 저장됩니다. PC를 옮기거나 새 버전을 설치할 때 data 폴더를 함께 보관하세요.
