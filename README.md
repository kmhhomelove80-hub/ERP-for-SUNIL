# 선일 통합 수주관리 6.0.1

[전체 프로그램 다운로드](sunil-delivery-6.0.1.zip?raw=true)

HMD 시트의 거래처가 ERP에서는 현대중공업 등으로 분류된 경우 금액이 누락되던 조건을 수정했습니다. 시트 이름을 거래처와 같다고 가정하지 않고 POR·호선·ERP CODE와 수주 참조를 대조합니다. 중복 거래처·서로 다른 단가는 확인 대상으로 유지합니다.

단가는 여전히 공급가액 ÷ 원래 수주수량이며 출고잔량으로 나누지 않습니다. 기존 6.0 기능과 탭 재사용 수정도 포함한 전체 설치본입니다.

서버 종료 및 기존 폴더 백업 → 새 폴더에 전체 압축 해제 → 기존 data 폴더 전체 복사 → start.bat 실행 → Ctrl+F5. 최초 실행 시 저장된 원본으로 수주현황을 재계산하므로 RAW 재업로드가 필요하지 않습니다. 이미 확정한 출고내역·전송 스냅샷은 유지합니다. ERP 서버를 다시 패치하지 않습니다.

95개 테스트 통과. 업무 엑셀·DB·비밀번호·내부 ERP 주소는 포함하지 않습니다.
