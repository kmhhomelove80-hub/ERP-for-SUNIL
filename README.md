# 선일 통합 수주관리 5.0

- [수주관리 다운로드](sunil-delivery-5.0.zip?raw=true)
- [ERP 서버용 왕복 연계 패치](sunil-erp-bridge-patch.zip?raw=true)

수주관리는 별도 폴더에 압축 해제하고 기존 data 폴더를 복사한 뒤 start.bat을 실행하세요.
ERP 패치는 실제 ERP 서버에서 적용합니다. 포함된 README를 확인하고 서비스 종료 후 install.bat 실행, 적용 후 서비스를 재시작하세요. 기존 코드 버전이 다르면 적용을 중단합니다.
수주관리의 ERP 설정에서 실제 ERP 주소를 입력하세요. 업무 데이터, DB, 비밀번호, 내부 ERP 주소는 포함하지 않습니다.
