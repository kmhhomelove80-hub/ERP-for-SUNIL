# 선일 통합 수주관리 6.0 · 전체 설치본

**[전체 프로그램 다운로드](sunil-delivery-6.0.zip?raw=true)**

## 반영사항
- 추출 수량 숫자 더블클릭 편집, Enter/다른 셀로 저장, Esc 취소. 합계·금액 자동 계산.
- 엑셀 방식 헤더 필터: 검색, 모두 선택, 개별 체크, 확인/취소/해제.
- 일반값 가운데, 수량·합계·금액 오른쪽 정렬.
- ERP 원수주수량 기준 단가 적용. 출고잔량을 단가의 분모로 사용하지 않음.
- ERP 전송 기록 행별·선택 삭제, 삭제 이후 회신 차단. ERP 예약·확정 출고는 유지.
- 전용 ERP 탭 재사용 및 기존 입력 교체 확인.
- 기존 SET, 열 너비 저장, 출고 누적, 주간 마감, RAW 연결·복구 기능 포함.

## 기존 사용자 적용
1. 수주관리 서버를 종료하고 기존 폴더를 백업합니다.
2. ZIP 전체를 **새 폴더**에 압축 해제합니다.
3. 기존 **data 폴더 전체**를 새 폴더로 복사합니다.
4. 새 폴더의 **start.bat** 실행 후 브라우저에서 **Ctrl+F5**를 누릅니다.

현재 v3 연동 수정본을 적용한 ERP 서버는 다시 패치하지 않습니다. 사내 ERP 주소는 기존 data 설정을 이어서 사용하거나 추출의 설정에서 입력하세요.

기존 확정 출고내역과 전송 자료는 소급 변경하지 않습니다. 새로 추출한 자료부터 새 금액 기준이 적용됩니다.
매칭 실패·원수량 없음·다른 단가 중복·과세 불명 항목은 확인 필요로 표시합니다.

검증: 서버 테스트 91개, Chromium 웹 UI 및 교차 주소 모의 ERP 회신 검증 통과. 실제 사내 ERP 서버에는 접속하거나 변경하지 않았습니다.

업무 데이터·DB·비밀번호·내부 ERP 주소는 포함하지 않습니다.
