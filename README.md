# 선일 통합 수주관리 7.0 · 전체 설치본

**[전체 프로그램 다운로드](sunil-delivery-7.0.zip?raw=true)**

## 반영사항
- 기존자료의 원본 합계 보존. 같은 코드의 다른 출고 건을 한꺼번에 합산하지 않음.
- 수주현황·추출·출고내역관리 엑셀형 필터와 필터 결과 기준 총수량·공급가액 합계·금액 미확인 건수.
- Ctrl+드래그 사각 셀 선택, Ctrl+C 복사, Esc 해제. 가상 스크롤·자동 스크롤 지원.
- ERP 타이틀은 SET 사용. 서로 다른 SET 또는 빈 SET이면 전송 전 입력. 전송 7열·예약 회신·중복 예약 방지는 유지.
- 앞선 수량 편집·단가 계산·HMD 금액 수정·전용 ERP 탭 재사용 등 포함.

## 기존 사용자 설치
1. 수주관리 서버를 종료하고 기존 프로그램을 백업합니다.
2. ZIP 전체를 **새 폴더**에 압축 해제합니다.
3. 기존 **data 폴더 전체**를 새 폴더에 복사합니다.
4. 새 폴더의 **start.bat** 실행 후 브라우저에서 **Ctrl+F5**를 누릅니다.

기존 ERP 서버의 연동 패치는 그대로 사용합니다. 사내 ERP 서버를 다시 패치할 필요가 없습니다.

기존자료 합계 값은 저장된 원본 기준으로 표시합니다. 구버전 자료는 병합 구간 정보가 없으므로 임의 병합하지 않습니다. **이전에 등록한 것과 동일한 원본 파일**을 같은 조선소 표시로 다시 가져오면 중복 등록 없이 병합 구간을 복원합니다. 상태·메모·수량은 유지합니다. 수정한 다른 파일은 새 자료로 추가될 수 있습니다.

일반 추출의 다운로드·ERP 전송·출고 확정은 현재 필터로 남은 행만 처리합니다. 예약 회신 화면은 예약 원본 전체를 유지합니다. 출고내역 주간 마감은 현재 조회 결과 중 ERP 출고 완료만 처리합니다.

검증: 서버 테스트 106개, Chromium 실제 클립보드·사각 선택·필터 집계·가상 스크롤·SET 타이틀 전달·모의 ERP 예약 회신 통과. 실제 사내 ERP 서버에는 접속하거나 변경하지 않았습니다.

업무 엑셀·DB·비밀번호·내부 ERP 주소는 포함하지 않습니다. 자세한 기능은 ZIP의 README.md를 확인하세요.
