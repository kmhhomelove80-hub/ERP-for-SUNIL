# 선일 납품리스트 웹앱

Python 3.12 이상. 기존 ERP 프로젝트와 독립된 웹앱입니다.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Windows에서는 `start.bat`을 실행하면 설치와 브라우저 열기를 진행합니다.
수동 실행 시 브라우저에서 http://127.0.0.1:8000 에 접속합니다.
기준 엑셀(XLSB/XLSX/XLSM 또는 ZIP)을 올리고, 필요한 경우 ERP 수주 원본을 추가합니다.
조선소와 POR 조건을 선택해 추출한 뒤 XLSX를 다운로드합니다.
기준 엑셀의 REF·SET 및 각 조선소의 N열 이후 원본 자료를 사용하며 매크로나 수식은 실행하지 않습니다.
POR 조건은 정확히 일치하는 값으로 검색하며 빈 목록은 전체 추출입니다. 기존 고급필터의 와일드카드/비교 연산자 표현은 지원하지 않습니다.
SHI·ICOPS는 준비 상태이며 app/engine.py의 ADAPTERS 등록부와 필요 시 전용 보정으로 확장합니다.

## 운영 범위
현재 단일 프로세스, 한 사용자 PC에서 실행하는 1차 버전입니다. 업로드는 파일당 25MB, ZIP 확장 크기는 100MB까지입니다.
세션 자료는 메모리에 저장되며 1시간 이후 접근할 수 없습니다. 만료 자료는 다음 업로드 때 또는 서버 재시작 때 제거됩니다.
인증 없는 공개 서버로 배포하지 마세요. 사내 다중 사용자 배포 시 로그인·TLS·서버 측 저장 정책을 추가해야 합니다.
엑셀 다운로드는 변환 결과를 담은 새 XLSX이며 원본 매크로·서식 전체를 복제하지 않습니다.

REF에 없는 거래처는 미분류로 유지하고 화면에 표시합니다. 중소 자동 추출에서는 제외되며, 기준 엑셀 REF에 등록 후 다시 업로드하면 반영됩니다.

## 거래처 분류 관리
자료 업로드 후 왼쪽의 ‘거래처 분류 관리’에서 미등록 거래처 또는 새 거래처를 정의합니다.
원본 거래처명, 표시할 조선소명, 대형/중소 구분을 입력하고 ‘분류 저장·적용’을 누릅니다.
현재 ERP를 다시 계산하므로 목록 추출을 다시 실행해야 합니다.
설정은 서버의 `data/classifications.sqlite3`에 보관되며 서버 재시작 후에도 유지됩니다.
저장한 설정은 엑셀 REF보다 우선합니다. 원본 REF 파일은 수정하지 않습니다.
진우엔지니어링주식회사와 세진기술산업(주)는 사용자 확인에 따라 중소로 기본 등록했습니다.
서버를 옮길 때에는 소스와 별도로 이 DB를 백업·이동하세요. 소스 ZIP에는 사용자 설정 DB를 넣지 않습니다.
